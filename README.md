# TomVanish

A simple vanish plugin. Make your staff invisible and make your server moderation better :D

## Commands

* `/vanish [player]` - Toggle vanish mode (broadcasts fake quit/join messages).
* `/v [player]` - Alias for `/vanish`.
* `/silentvanish [player]` - Toggle vanish mode silently without sending join/quit messages.

## Permissions

* `vanish.use` - Allows a player to vanish themselves using `/vanish`.
* `vanish.silent` - Allows a player to use `/silentvanish`.
* `vanish.others` - Allows vanishing or unvanishing other players.
* `vanish.see` - Allows seeing vanished players and prevents receiving fake join/quit messages.
